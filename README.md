## ⚔️ O Domínio de Rimuru

Desenvolvido para capturar a essência do universo de *Tensura*, este portal combina uma estética de alta fantasia e magia com uma interface fluida, moderna e responsiva. Aqui, a burocracia humana dá lugar à Federação de Jura.

### ✨ Destaques do Hub
- **Capital Central (Home):** Uma recepção cinematográfica com a identidade visual de Rimuru Tempest em tons de azul mágico e ciano.
- **Enciclopédia de Cidadãos:** Fichas detalhadas dos protetores de Jura Tempest — de Benimaru e Shion a Ranga e os Lordes Demônios.
- **Grimório de Habilidades:** Um registro interativo das evoluções do *Grande Sábio* (*Great Sage* / *Raphael*) e magias lendárias.
- **Crônicas de Jura:** Acompanhe os arcos da história que transformaram um simples slime no governante de uma nação.

## 🔮 Grimório Tecnológico

O projeto foi forjado utilizando ferramentas modernas de desenvolvimento web para garantir performance e elegância:

* **Interface:** HTML5 semântico e CSS3 para estilização ágil com variáveis de tema customizadas.
* **Dinamismo:** JavaScript (ES6+) para manipulação de componentes, filtros e animações de interface.
* **Tipografia & Estética:** Design system inspirado na paleta de cores e na atmosfera mística do anime.
